# 🚀 Hackathon Registration Website 2026

A modern, fully responsive landing page for a tech hackathon event. Built as a frontend-only solution with interactive features, dynamic UI, and seamless deployment.

🔗 **Live Demo:** https://ui-six-black.vercel.app/ 
📂 **GitHub Repo:** https://github.com/anshu25bai11353-coder


## 📋 Project Overview

This is a static single-page application designed to attract and register participants for a 48-hour hackathon. It combines clean UI/UX with client-side interactivity to provide an engaging experience for visitors. The site is fully responsive and works flawlessly on mobile, tablet, and desktop devices.



## 🎯 Mandatory Sections Included

- ✅ **Home** – Hero section with branding, call-to-action, and key stats
- ✅ **About** – Overview of the event and its mission
- ✅ **Schedule** – Interactive timeline with event itinerary
- ✅ **Prizes** – Prize categories with amounts and descriptions
- ✅ **Sponsors** – List of partner organizations
- ✅ **Registration Form** – Fully functional frontend form with validation



## ✨ Bonus Features (3+ Implemented)

### 1. 🌗 Dark Mode Toggle
- Manual toggle button in the navigation bar to switch between Light and Dark themes.
- User preference is saved locally (`localStorage`) so the theme persists across page reloads.
- Smooth transitions for all UI elements when switching themes.

### 2. ⏳ Countdown Timer
- A dynamic countdown timer on the Hero section that counts down to the event kickoff.
- Updates every second in real-time (Days, Hours, Minutes, Seconds).
- Automatically stops at zero when the event begins.

### 3. 🎞️ Scroll-Reveal Animations
- Sections fade and slide into view as the user scrolls down.
- Uses the Intersection Observer API for smooth, performant animations.
- Creates a polished, professional feel without overwhelming the user.

### 4. 🗓️ Interactive Timeline
- The Schedule section displays event days in a vertical timeline.
- Each timeline item staggers its reveal animation.
- Includes visual dots and connecting lines for clarity.

### 5. ✅ Form Validation
- Registration form validates all required fields (First Name, Last Name, Email, Reason).
- Displays clear, inline error messages for invalid inputs.
- On successful validation, shows a success confirmation message.

### 6. 🖼️ Gallery Section
- A visual grid displaying emoji icons representing past event moments.
- Includes hover tooltips with descriptive labels for each image.
